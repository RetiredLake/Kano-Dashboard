      ABOUT THIS WEB PORT
      
    Make it with code.
    
      
    This is an original browser learning sandbox inspired by Kano Hack Minecraft. The isometric world and lessons are powered by a JavaScript MCPI API adapter. The blocks below generate familiar Python code so you can learn the ideas behind Pi Edition projects.
    
      
    The browser exposes window.mcpi to JavaScript. Web pages cannot open the original Minecraft TCP port 4711, so this API works locally in the sandbox. The native Linux client is a separate MCPi-Reborn install and requires Minecraft game files obtained by the user.
