# Hack Minecraft web port

This directory is the source and deployable version of the browser learning sandbox. It is an original implementation guided by Kano's public `make-minecraft` app metadata and the public MCPI-Reborn API documentation. The standalone Kano source repository could not be recovered from the public Kano organization, so this port does not claim to be the original Kano code.

## Run it

Open `/hack-minecraft/` from the Kano dashboard. It is a static, dependency-free web app. The dashboard tile uses `icon.png`; replace that icon only with artwork you have rights to use.

The browser app provides four original lessons, an editable visual block stack, Python code preview, local isometric world, progress saving, and a JavaScript adapter at `window.mcpi`. The block store and coordinate lookup run in `world-core.wasm`; the MCPI adapter, lesson logic, and rendering run in JavaScript. The app falls back to its JavaScript block store if WebAssembly is unavailable. Generated Python is instructional output; this page does not embed a Python interpreter.

## Web API

`api.js` exports `BLOCKS` and `createMcpiWebApi()`. The returned adapter exposes `world`, `player`, `entity`, `chat`, `camera`, `events`, and `dispatch(commandLine)`. Its implemented MCPI/RaspberryJuice calls include:

| Area | Implemented in browser |
| --- | --- |
| World blocks | block reads/writes, cuboids, height, player IDs, signs, entity/type lists, spawn/remove entities/items, seed and game mode |
| Checkpoints/settings | `world.checkpoint.save/restore`, `world.setting` for `autojump`, `nametags_visible`, `world_immutable`, world time |
| Player/entity | player and entity position/tile/absolute-position, name/type/ID, rotation/direction/pitch, velocity, selected-item read |
| Chat/camera/events | `chat.post`, camera normal/fixed/follow and `setPos`, block-hit/chat/projectile event queues and clearing |
| Reborn compatibility | compatibility-mode and null-response toggles; `dispatch()` accepts the matching MCPI/RaspberryJuice line-command names |

The browser world emulates API state, not the native game's physics, AI, inventory interactions, multiplayer, or persistent entities. It returns a fixed seed and game mode. Region writes are limited to 32,768 blocks, and entity events can be injected by a lesson or UI action rather than generated by a simulated game. A web page cannot open MCPI-Reborn's original TCP port 4711, so `dispatch()` is an in-process adapter, not a network server. `window.mcpi` is page-local and block/lesson changes are saved in this browser's local storage.

Linux bundles add a loopback HTTP-to-TCP bridge. In that mode, **MAKE** mirrors the blocks into the browser world and forwards corresponding `world.setBlock`, `world.setBlocks`, `player.setPos`, and `chat.post` calls to an already running MCPI-Reborn API at `127.0.0.1:4711`. The hosted page never probes or connects to localhost.

## Native Linux Minecraft client

MCPI-Reborn is tracked separately as an upstream source snapshot under `sources/minecraft-pi-reborn`. It is an open-source modding project for Minecraft: Pi Edition and supports x86-64 and ARM64 on suitable GNU/Linux systems. It does not contain Minecraft PE 0.6.0 source; its setup refers to PE 0.6.1 `libminecraftpe.so` as an optional sound input. No proprietary client library, texture archive, or sound assets are included here.

The Kano lesson UI and web API are architecture-independent static files. A Linux browser can open the hosted lesson site on ARM64 or x86-64. The local Linux bundles also include an optional port-4711 bridge. No PE binary or assets are included. See `sources/minecraft-pi-reborn/docs/INSTALL.md` and `docs/GETTING_STARTED.md` for the native client's install and data requirements.

## Tests

Run the browser API and WebAssembly tests from the Site checkout:

```sh
node --test tests/hack-minecraft-api.test.js
node --test tests/hack-minecraft-wasm.test.js
```

Rebuild the checked-in Wasm core with Emscripten using `bash src/hack-minecraft/build-wasm.sh`.
